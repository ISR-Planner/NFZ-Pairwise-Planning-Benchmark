# Part I Public Benchmark Evidence

This directory documents the public Part I evidence for the NFZ-aware pairwise cost-matrix benchmark.

## Scope

- 12 mission environments: 9 controlled and 3 composite adversarial.
- 9 primary methods.
- 108 unique method-environment conditions.
- 2 completed repetitions.
- 216 total executions.

Controlled Run 1 outputs are under `../methods/`. Controlled Run 2 outputs are under `../main_benchmark_replications/`. Composite Run 1 and Run 2 outputs are under `../composite_adversarial_replications/`.

The public release inventory and checksum metadata are at repository root in `PUBLIC_RELEASE_MANIFEST.md`, `PUBLIC_RELEASE_MANIFEST.json`, and `SHA256SUMS.txt`. The frozen private Part I manifest is intentionally not copied because sanitation and approved omissions make it an inaccurate description of the public tree.

See `../../PROVENANCE.md` for the internal source and sanitized release-candidate commit anchors.
