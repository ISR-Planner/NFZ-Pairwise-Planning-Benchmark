# Part II Schemas

This directory contains machine-readable JSON Schemas for Part II artifacts.

- `proposed_pair_diagnostics.schema.json`: one directed-pair diagnostic row for
  Proposed diagnostic mode.
- `proposed_environment_summary.schema.json`: per-environment Proposed diagnostic
  branch counts, percentages, and aggregate timing.
- `part2_primary_execution.schema.json`: one primary benchmark execution row.
- `part2_provenance_manifest.schema.json`: provenance manifests for generated
  Part II artifacts.

The schemas describe artifact shape only. They do not contain benchmark results.
